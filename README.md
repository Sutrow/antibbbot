# Avito Antibot

По событиям за сутки оцениваю вероятность того, что куки относится к трафику известных сервисов сбора данных.

**Результат отправки на Stepik: Precision@Recall≥0.70 = 0.76000.** Константный ответ — 0.09391.
Эта оценка получена на платформе, а не на локальной валидации.

## Структура

```text
avito-antibot/
├── data/
│   ├── train.csv
│   ├── test.csv
│   └── events.csv.gz
├── notebooks/
│   ├── 01_eda.ipynb
│   ├── 02_experiments.ipynb
│   └── 03_solution.ipynb
├── outputs/
│   └── submission.csv
├── features.py
├── metric.py
├── requirements.txt
├── .gitignore
└── README.md
```

| Ноутбук | Содержание |
|---|---|
| `01_eda.ipynb` | Данные, окна, дубликаты, пропуски и поведение классов |
| `02_experiments.ipynb` | Временная валидация, baseline, сравнение моделей и контроль |
| `03_solution.ipynb` | Обучение ансамбля и создание `outputs/submission.csv`; запускается отдельно |

В ноутбуках сохранены выводы выполненных ячеек. Проверки данных находятся там же.
В `features.py` — только подготовка событий и расчёт признаков. В `metric.py` сохранён расчёт официальной метрики;
проверки входов и самопроверки перенесены в ноутбуки.

## Запуск

Проверено на **Python 3.13.5**, CPU. Зависимости закреплены в `requirements.txt`.

```bash
python -m pip install -r requirements.txt
python -m jupyterlab
```

Открыть `notebooks/03_solution.ipynb` и выполнить все ячейки. Для просмотра исследования начать с `01_eda.ipynb`.

В архиве исходные данные уже лежат в `data/`. При работе с Git они исключены через `.gitignore`.

## Решение

События ограничены собственным окном куки: `window_start_ts <= event_ts < window_end_ts`.
Точные дубликаты удаляются. Платформенные алиасы нормализуются, а неопределённые числовые статистики остаются `NaN`.

Использую 597 признаков: объём и состав действий, интервалы и сессии, разнообразие объявлений и категорий,
поиск, нормализованный браузерный контекст, относительную геометрию координат курсора.
Сырые идентификаторы, запросы, User-Agent и абсолютные даты в модели не передаются.

Итог — среднее оценок LightGBM и CatBoost с весами 0.5 / 0.5. Seed обеих моделей — 2026.
Параметры заданы в финальном ноутбуке. Порог в submission не применяется.

| Модель | 11–13 апреля | 14–16 апреля | Контроль 17–19 апреля |
|---|---:|---:|---:|
| RF из quickstart, 2 признака | 0.095628 | 0.105223 | 0.108213 |
| Предыдущий LightGBM, 414 признаков | 0.578512 | 0.631336 | 0.592593 |
| Итоговый ансамбль, 597 признаков | 0.654206 | 0.695431 | 0.654971 |

Модель выбрана по двум development-периодам. Контроль уже просматривался при разработке,
поэтому его результат — диагностика, а не полностью независимая оценка.
Разметка относится к известным сервисам; перенос на неизвестные источники отдельно не проверен.

## Сохранение результата

В `outputs/submission.csv` лежит прежний отправленный файл без изменений.
После переоформления финальный ноутбук запущен заново: все **4 909 оценок совпали точно** при сопоставлении по `cookie_id`.
Пересозданный файл записывается в порядке строк `test.csv`; порядок не влияет на метрику.
Проверка совпадения со старым CSV не участвует ни в обучении, ни в расчёте оценок.

Использованы open-source библиотеки NumPy, pandas, scikit-learn, SciPy, LightGBM, CatBoost, joblib и Matplotlib.
Код выполняется локально, без внешних API и языковых моделей.
